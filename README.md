# Global Temperature Anomaly Visualizer 🌍🔥

A simple, beautiful Python tool that downloads **real NASA GISS data** and visualizes **global temperature anomalies** — clearly showing the rapid warming trend due to climate change.

## Features
- Downloads the **latest** global temperature anomaly data directly from NASA
- Creates professional line plot (1880–present) + bar chart of the last 20 years
- Uses real, live data — updates every time you run it
